# The Break — Café & Glaces

A simple responsive café website matching the supplied design.

The website is intentionally **not an online shop**:
- No product cards
- No Add buttons
- No cart
- No checkout
- No delivery
- No table reservation

Customers simply browse the menu, see prices, find the café, and come in to order.

Open `index.html` in a browser or use VS Code Live Server.
